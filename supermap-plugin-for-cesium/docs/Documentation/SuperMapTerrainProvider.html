Class: SuperMapTerrainProvider

SuperMapTerrainProvider

new SuperMapTerrainProvider(options)

用于加载发布的地形服务‌。

Name Type Description
options Object

包含以下属性：

Name Type Default Description
url String

地形服务的url。
proxy Proxy 可选

服务代理。
requestVertexNormals Boolean false 可选

是否请求法线（用于光照效果），默认不请求。
requestWaterMask Boolean false 可选

是否请求水面标志位（用于水面特效），默认不请求。
ellipsoid Ellipsoid 可选

椭球体，默认为WGS84。
credit Credit | String 可选

服务描述信息。
isSct Boolean true 可选

是否为iServer发布的TIN地形服务,stk地形设置为false。
isShowGlobe Boolean 可选

是否剔除无效地形区域,默认为true（全球显示）。
packingRequest PackingRequest 可选

批量请求编码方式。
Example
var  terrainProvider = new SuperMapCesiumPlugin.SuperMapTerrainProvider({
	                        url : ‘http://localhost:8090/Terrain’,
		                    requestWaterMask : true,
		                    requestVertexNormals : true,
		                    isSct : true
                     });
var viewer = new Cesium.Viewer("cesiumContainer",{
                  terrainProvider : terrainProvider
             });

hasVertexNormalsBoolean

获取当前地形是否有顶点法线。 不能在SuperMapTerrainProvider#ready 返回TRUE之前调用。

hasWaterMaskBoolean

用于判断当前地形服务是否包含水面掩膜数据。

readonly historyVersionsString

获取地形数据的所有历史版本信息。目前仅支持tin地形数据。

indexedDBSettingObject

获取或者设置地形的indexedDB瓦片是否开启(IE浏览器不支持)。

Example
//设置是否保存地形瓦片到浏览器的indexedDB数据库
viewer.terrainProvider.indexedDBSetting.isOpen = true

isShowGlobeBoolean
