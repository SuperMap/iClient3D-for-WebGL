Camera

new Camera()

Cesium插件相机扩展对象

Members

flyCircleLoopBoolean

设置相机绕点旋转是否开启循环模式。

Example
var scene = viewer.scene;
var camera = scene.camera;
//设置相机循环模式
camera.flyCircleLoop = true;

sensitivePositionRatioNumber

获取或设置地形敏感点比例，范围为0-1之间。

speedRatioNumber

设置绕点旋转速率。（负数则反向旋转）
