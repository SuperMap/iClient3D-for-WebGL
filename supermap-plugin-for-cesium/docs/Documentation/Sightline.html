Class: Sightline

Sightline

new Sightline(scene)

视线分析，即通视分析，根据观察者点位和目标点建立视线分析，并在场景中分析得到结果。

Name Type Description
scene Scene

场景对象。
Throws:

scene are required。

Type
DeveloperError
Example
//创建通视分析
var sightline = new SuperMapCesiumPlugin.Sightline(scene);

Members

hiddenColorColor

获取或设置通视分析的不可见部分颜色。

Default Value:
SuperMap3D.Color(1.0,0.0,0.0,1.0)
Example
var sightline = new SuperMapCesiumPlugin.Sightline(scene);
var color = new Cesium.Color(1, 0, 0);
//设置不可见部分的颜色
sightline.hiddenColor = color;
//获取不可见部分的颜色
var value= sightline.hiddenColor;

lineWidthnumber

获取或设置通视线的宽度。

Default Value:

viewPositionArray

获取或设置观察者的位置。位置由经度、纬度和高程组成的数组表示。

Default Value:
[0.0,0.0,0.0]
Example

//设置观察者的位置
