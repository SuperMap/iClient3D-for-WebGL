Class: ProjectionImage

ProjectionImage

new ProjectionImage(scene)

视频投放类。将图片或视频投放到场景中，可模拟建筑物上的广告幕布或大屏电视效果。

Name Type Description
scene Object

指定用于分析的场景对象。
Throws:

必须指定场景scene。

Type
DeveloperError
Example
//创建视频投放
var projectionImagee= new SuperMap3D.ProjectionImage(scene);.
