open(url, sceneName, options){Promise}

打开iserver场景服务下所有图层

Name Type Description
url String

服务url
sceneName String

工作空间中有多个场景，需要指定场景名称；设置为undefined，默认打开第一个
options Object 可选

对象具有以下属性:

Name Type Default Description
subdomains Array

用于子域，例如：['t1','t2']。
autoSetView Boolean true 可选

是否自动定位到场景
Returns:
Type Description
Promise 返回promise异步加载对象
Example
var promise = supermapPluginViewer.scene.open('http://localhost:8090/iserver/services/3D-BIM3/rest/realspace');
promise.then(function(layers){});

//子域和不自动定位用法
var promise = supermapPluginViewer.scene.open('',undefined,{
    subdomains: ['t1', 't2']，//子域
    autoSetView : false      //不自动定位
});
promise.then(function(layers){});
